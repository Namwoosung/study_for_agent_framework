# Google ADK 학습 페이지

`index.html`을 브라우저에서 열어 읽습니다. 생성된 페이지는 설치·서버·인터넷 없이 본문과 도식을 표시합니다. 공식 출처 링크를 열 때만 인터넷 연결이 필요합니다.

원문은 상위 폴더의 `Google_ADK.md`입니다. 원문 기준은 2026-10-29, Python v2.13.0입니다. `AGENTS.md`의 교재 원칙을 적용해 17px 본문·제한된 읽기 폭·단순한 목차를 사용합니다.

9개 학습 단원은 기초 → 설정·도구·모델 → Event와 저장 → 실행 루프 → Workflow → 운영 → 코드 → 반도체 설계 → 비교 순서입니다. 학습 안내, 용어집, 출처 페이지를 포함해 총 12페이지입니다. 66개 장과 읽기 안내·부록을 보존했으며, 원문의 미실행 코드·설계 제안·버전 조건을 유지합니다. 별도 진도·채점·계정·저장 기능은 없습니다.

흐름도는 연결 방향과 분기 라벨을 보존한 로컬 SVG로, 호출 순서는 반복·분기 구간을 보존한 표 형태 순서도로 표시합니다. 원래 Mermaid 코드는 각 도식 아래에 보존합니다. 코드는 실행하지 않습니다.

## 파일과 재생성

`site.config.mjs`는 단원별 편집 안내와 원문 대응을, `build.mjs`는 HTML·SVG 생성을, `validate.mjs`는 원문 섹션·코드·도식 누락과 링크 검사를 담당합니다. `content-map.json`에는 원문 해시와 대응 관계를 기록합니다.

이 폴더에서 실행합니다. 재생성에만 Node.js와 `marked`, `@viz-js/viz`가 필요하며 로컬 패키지 또는 Codex 번들 런타임을 사용합니다.

```powershell
node build.mjs
node validate.mjs
```

Python이 설치된 환경에서 선택적으로 미리 볼 수 있습니다.

```powershell
python -m http.server 8767 --bind 127.0.0.1 --directory ..
```

브라우저에서 `http://127.0.0.1:8767/html/`을 엽니다. 종료는 Ctrl+C입니다.

이 웹페이지 작업은 사용자의 원문 편집·표시이며, 최신 SDK 구현·공식 문서를 새로 조사하거나 실제 모델 실행·벤치마크를 수행한 것은 아닙니다.
