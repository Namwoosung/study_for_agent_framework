읽는 법: 1차와 2차의 차이#

1차 학습에서 LlmAgent, Runner, Session, Tool, Workflow의 기능을 이해했다면, 여기서는 실제로 어느 함수가 이벤트를 만들고 소비하는가, 누가 루프를 멈추는가, 무엇이 디스크에 남고 무엇은 남지 않는가를 묻는다. 기능을 지원한다는 사실만으로 끝내지 않는다. 모든 장에서 문제 → 코드 경로 → 상태/분기 → 기술적 이유 → 실패 모드 → 비교 포인트를 따라간다.

2차 학습의 핵심 질문 18개#

  1. Runner.run_async()에서 루트가 LlmAgent, 기존 BaseAgent, 2.0 Workflow인 경우 서로 다른 실행 경로는 무엇인가?
  2. 하나의 사용자 입력이 Event, InvocationContext, Session에 각각 어떻게 표현되는가?
  3. LLM 호출 루프의 정확한 단위는 무엇이며, 종료 판정은 어떤 조건으로 이루어지는가?
  4. 프롬프트는 어떤 Processor를 어떤 순서로 통과하고, 어느 단계에서 Tool 목록이 확정되는가?
  5. 모델이 FunctionCall 여러 개를 내면 누가 조회·검증·실행·응답 병합을 수행하는가?
  6. 병렬 Tool의 결과는 어떤 순서로 모델에 복귀하며, 중간 실패 시 이미 성공한 Tool은 어떻게 취급되는가?
  7. before_tool_callback을 실행하는 지점은 준비 단계인가, 실행 단계인가?
  8. Event.is_final_response()가 참이면 전체 애플리케이션 실행도 반드시 끝나는가?
  9. State의 temp:, user:, app: 키는 무슨 수명주기를 가지는가?
  10. Session History와 MemoryService의 검색 저장소는 어떻게 다른가?
  11. Context Caching과 Context Compaction은 서로 무슨 정보를 재사용·소실시키는가?
  12. ParallelAgent는 어느 Python 동시성 Primitive를 쓰고 Event를 어떻게 합치는가?
  13. ADK 2.0 Workflow의 Graph, BaseNode, Trigger와 실행 상태는 어떤 관계인가?
  14. HITL의 승인 대기는 Tool 호출 이전에 어떻게 만들어지며, 재개 시 무엇을 다시 실행하는가?
  15. 실패·취소·Checkpoint 복원에서 외부 부작용은 중복 실행될 수 있는가?
  16. Callback·Plugin·LLM 지침·Sandbox 중 어느 것이 진짜 실행 경계에서 강제되는가?
  17. HTTP Serving·Streaming·Cancel·Cron 등은 SDK 내장인가, 별도 실행 인프라의 책임인가?
  18. ADK와 Hermes/OpenAI Agents SDK/PydanticAI/MAF의 설계 철학이 어디에서 달라지는가?
