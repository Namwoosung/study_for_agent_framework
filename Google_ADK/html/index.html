먼저 잡을 큰 그림

Google ADK는 모델 자체가 아니라 Agent 애플리케이션을 개발하고 실행하는 프레임워크입니다. LlmAgent가 모델 중심 행동을 정의하고, Runner가 서비스·세션·실행 컨텍스트를 연결합니다.

이 교재에서는 요청이 Event 흐름으로 처리되는 과정을 중심으로 읽습니다. 현재 상태와 과거 기억, 파일 결과물을 구분한 뒤, 모델의 판단과 코드로 정한 Workflow가 어떻게 만나는지 확인합니다.

학습 원문을 근거로 재구성한 안내입니다. 원문의 근거 표기와 검증 범위를 함께 확인하세요.

서로 구분하며 읽을 개념

Agent / Runner / Event
Agent는 작업 행동을 정의하고, Runner는 실행 환경을 관리하며, Event는 메시지·행동·상태 변화를 전달합니다.
Session / State / Memory / Artifact
대화 이력, 구조화된 현재 값, 별도로 검색할 과거 정보, 파일 결과물은 저장 목적과 수명주기가 다릅니다.
모델 기반 판단 / 명시적 Workflow
모델이 다음 행동을 고르는 흐름과 코드·그래프로 순서와 분기를 정의하는 흐름을 구분합니다.
