# 전체 학습 홈

프로젝트 루트의 [index.html](../index.html)이 모든 교재를 연결하는 시작 페이지입니다. 파일을 브라우저에서 열면 인터넷이나 서버 없이 사용할 수 있습니다.

- 7개 주제의 1차 기본 교재와 2차 심층 교재를 분리해 표시합니다.
- 전체 227개 학습 페이지가 목차에 포함되어 각 단원으로 바로 이동할 수 있습니다.
- 모든 학습 페이지의 `전체 학습 홈` 버튼은 루트 index.html로 돌아옵니다.
- 프로젝트 공통 Markdown 자료도 홈 아래쪽에서 열 수 있습니다.

프로젝트 루트에서 갱신·검사합니다.

```sh
node html/build-home.mjs
node html/validate-home.mjs
```

홈 생성은 각 교재의 content-map.json과 생성된 HTML 제목을 사용합니다. Node.js 기본 모듈만 사용하며 별도 패키지는 필요하지 않습니다. 출력된 홈은 CSS를 포함한 단일 정적 HTML 파일입니다.

각 주제의 html/link-courses.mjs는 기본·심층 페이지에 경로 깊이에 맞는 홈 링크를 추가합니다. 기존 교재 빌드에서도 호출하므로 재생성해도 링크가 유지되며, 전체 홈 목차도 함께 갱신됩니다. 기본·심층 본문과 원본 Markdown은 변경하지 않습니다.

validate-home.mjs는 목차와 실제 HTML 파일 목록이 일치하는지, 모든 페이지가 홈으로 돌아오는지, 로컬 파일·앵커 참조가 유효한지 검사합니다. 원문 내용 검사는 각 교재의 기존 validate.mjs로 수행합니다.
