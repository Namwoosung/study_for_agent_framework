원문 기준 2026.10.29 · Python v0.24.0

먼저 잡을 큰 그림

OpenAI Agents SDK는 완성된 업무 서비스가 아니라, 모델과 도구를 연결하고 반복 실행을 관리하는 개발 SDK입니다. Agent에 지침·모델·도구를 선언하면 Runner가 모델 응답을 해석해 실행을 이어갑니다.

도구 실행, 다른 Agent로의 제어권 이전, 승인 대기와 최종 응답은 서로 다른 상태입니다. 이 교재에서는 그 상태 전이를 중심으로 실행·저장·보안 경계를 연결합니다. 업무의 수치 정확성과 실제 접근권한은 별도 검증이 필요합니다.

학습 원문을 근거로 재구성한 안내입니다. 원문의 근거 표기와 검증 범위를 함께 확인하세요.

서로 구분하며 읽을 개념

Agent / Runner / Responses API
Agent는 실행 구성이고 Runner는 반복을 관리합니다. 모델 API의 응답 생성과 로컬 도구 함수 실행은 같은 작업이 아닙니다.
Handoff / Agent-as-Tool / 코드 절차
Handoff는 현재 대화의 제어권을 이전합니다. Agent-as-Tool은 상위 Agent가 결과를 받아 종합하며, 고정 순서는 코드로 정할 수 있습니다.
로컬 Context / 모델 Context / Session / RunState
로컬 의존성, 모델에 전달되는 정보, 대화 이력, 중단된 실행의 복원 상태는 목적과 전달 범위가 다릅니다.

이 교재의 범위

상위 폴더의 OpenAI_Agents_SDK.md를 바탕으로 편집했습니다. 본문·코드·표·출처와 원문의 제약을 보존하며, 도식은 로컬에서 읽을 수 있도록 다시 표시합니다.

Python openai-agents v0.24.0에 대한 원문 정적 분석이며, 일반 Agent 경로와 Sandbox 확장의 범위를 구분합니다. 이번 웹페이지 제작은 원문의 편집·표시 작업입니다. 최신 API나 구현을 추가 조사한 것으로 간주하지 않으며, 실제 설치·모델 호출·벤치마크는 수행하지 않았습니다.
