검증 상태: 공식 문서와 GitHub의 v0.24.0 태그를 대조하여 확인한 정적 분석. 패키지 설치·LLM 호출·성능 벤치마크는 실제 수행하지 않음.

이 문서를 읽는 방법#

  • [공식] 공식 설명에 문서화된 사실, [소스] 공개된 해당 버전의 구현에서 확인한 사실, [설계 판단] 반도체 활용을 위한 분석적 권고, [의사코드] 학습 편의를 위해 단순화한 로직을 뜻한다.
  • Agent, Runner, FunctionTool, RunState와 같은 영어 식별자는 실제 API나 구현을 가리킨다.
  • 원본 링크에는 가능하면 릴리스 태그(v0.24.0)를 사용한다. 공식 웹 문서는 계속 변경될 수 있어 최신 문서와 해당 릴리스 코드는 반드시 구분한다.
  • 코드는 학습용으로 작성했으며 별도 표시가 없는 한 실행 여부 미검증이다. 작성 시점의 구체적인 모델명·요금·모델별 지원 기능을 고정된 사실로 가정하지 않는다.
  • 핵심 경계: SDK의 입력·출력 형식 검증은 반도체 분석 결과의 사실 정확성·계산 타당성을 보장하지 않는다.

29.2 정확한 v0.24.0 소스 파일 목록#

중요: 이 표의 경로는 실제 v0.24.0 태그가 붙은 저장소 파일을 가리킨다. 주요 함수·클래스의 존재와 역할을 검증하는 데 사용했다. 내부 함수·클래스는 릴리스에 따라 이동하거나 변경될 수 있다.

ID 파일 분석 목적
C01 src/agents/agent.py Agent dataclass, Tool 수집 및 가시성
C02 src/agents/run_internal/run_steps.py ProcessedResponse, NextStep..., SingleStepResult
C03 src/agents/run_internal/turn_resolution.py 모델 응답 후 도구·위임·최종 상태 처리

C07 src/agents/run_internal/tool_planning.py 실행 계획·승인·중복 처리 고려

C11 및 S27/S28은 공식 저장소의 main 브랜치 문서이며, v0.24.0에 모든 내용이 존재했는지 이 표 자체가 증명하지 않는다. v0.24.0 확정 구현을 설명하는 근거는 같은 태그의 코드(C01–C10, C12)와 해당 릴리스 공식 문서·릴리스 노트를 우선한다.

29.3 추가 소스 코드 정밀 분석 과제 (직접 실행 단계용)#

현재 문서에서는 정적 코드 경로를 확인했지만, 다음은 실제 SDK 설치 및 테스트를 실행해야 확정할 수 있는 항목이다.

  1. 각 모델/API 제공자의 Tool Calling과 Structured Output 호환성.
  2. 여러 Function Tool 호출 시 병렬성, 순서, cancellation과 timeout 전파.
  3. Handoff와 중첩 Agent.as_tool()의 Context/Session/Trace 구성.
  4. Output Guardrail 실패 시 어느 항목이 저장·삭제·재생되는지.
  5. 승인 대기 후 RunState의 직렬화/복원과 재실행 시 중복 작업 여부.
  6. 로컬 MCP vs Hosted MCP에서 입력/출력의 전송 경계.
  7. Session 저장소의 동시 접근·충돌 및 다중 서버 운영 시 정확성.
  8. Sandbox Agent의 실제 파일·네트워크 격리, Skills 로딩 및 메모리 지속성.
  9. 서비스 요구사항에 맞춘 p50/p95 지연, 토큰·비용·오류율 측정.
  10. 고정된 합성 반도체 평가셋에서 Tool 선택·계산·근거 정확도.

29.4 정보 검증·저작 범위 선언#

  • 이 문서는 공식 문서와 공개 GitHub 소스에서 확인 가능한 사실에 집중했다.
  • 특정 내부 함수의 전체 소스코드를 문서에 복사하는 대신, 핵심 데이터 구조·실행 단계·대응 경로를 설명하고 원본 링크를 제공한다.
  • 의사코드는 핵심 동작을 이해하기 위한 재구성이며 실제 구현 원문·실행 보장을 뜻하지 않는다.
  • 프레임워크의 실측 성능, 어떤 모델에서의 품질 우열, 사내 LLM Gateway의 호환성 등은 테스트하지 않았기 때문에 확정적으로 평가하지 않았다.
  • 이론·업무 설계에서 추가 제안한 내용은 SDK의 자동 제공 기능으로 오인하지 않도록 설명했다.
