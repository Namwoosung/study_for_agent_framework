# Claude Code 학습 페이지

이 폴더의 `index.html`을 브라우저에서 열어 읽습니다. 본문·표·코드·도식은 설치·서버·인터넷 없이 표시합니다. 공식 출처 링크에는 인터넷 연결이 필요합니다.

원문은 상위 폴더의 `Claude_Code.md`입니다. 원문 조사 기준은 2026-10-30, Claude Code v2.1.310입니다. Claude 모델·Claude Code Harness·Agent SDK를 구분하며, 공개 문서·자료에서 확인한 내용과 비공개 엔진의 개념 모델·의사코드, 후속 실험과 설계 제안을 나누어 표시합니다.

루트 `AGENTS.md`의 교재 원칙에 맞춰 본문 17px, 제한된 읽기 폭과 단순한 목차를 사용합니다. 학습 안내, 9개 단원, 복습·연구 노트, 출처·검증 범위로 구성합니다. 원문의 23개 장·도입부·부록 3개와 코드·표·조건·링크를 보존합니다. 원문 복습 질문은 읽기용이며 채점·진도 추적·계정·브라우저 저장소를 추가하지 않았습니다.

흐름도는 관계와 화살표·분기를 보존한 로컬 SVG로, 호출 순서는 조건 분기를 보존한 표 형태 순서도로 표시합니다. Mermaid 원문을 각 그림 아래에 보존합니다. 원문의 # 단원 / ## 절 구조는 웹페이지의 h1 아래 h2 단원 / h3 절로 맞췄으며, 코드 블록의 Markdown은 변형하지 않습니다.

## 재생성과 검증

`site.config.mjs`는 단원별 편집 안내와 원문 대응, `build.mjs`는 HTML·SVG 생성, `validate.mjs`는 원문 섹션·코드·도식 누락과 로컬 링크·제목 ID 검사를 담당합니다. `content-map.json`에 원문 SHA256과 대응 관계를 기록합니다.

이 `html/` 폴더에서 실행합니다. 재생성에만 Node.js와 `marked`, `@viz-js/viz`가 필요하며 로컬 패키지 또는 Codex 번들 런타임을 사용합니다.

```powershell
node build.mjs
node validate.mjs
```

Python이 설치된 환경에서는 선택적으로 미리 볼 수 있습니다.

```powershell
python -m http.server 8768 --bind 127.0.0.1 --directory ..
```

`http://127.0.0.1:8768/html/`을 엽니다. 종료는 Ctrl+C입니다.

이번 웹페이지 제작은 사용자가 작성한 원문의 편집·표시입니다. 최신 제품 동작을 새로 조사하거나 실제 Claude Code 설치·실행, 보안 차단율·성능·반도체 정확도를 검증한 것은 아닙니다.

## 제작 검증 범위

12개 페이지, 27개 원문 섹션, 37개 코드 블록과 12개 도식의 포함 여부, 내부 링크 476개와 제목 ID를 검사했습니다. 원문 SHA256이 작업 전과 동일함을 확인했습니다. 좁은 브라우저에서 제목·본문·목차 개폐·단원 이동·출처 링크 표시와 제목 계층을 확인했습니다. 별도 데스크톱 해상도와 실제 모바일 기기에서는 검증하지 않았습니다.
