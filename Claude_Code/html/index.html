먼저 잡을 큰 그림

Claude Code는 Claude 모델 자체가 아니라, 모델이 파일을 탐색하고 코드를 수정하며 명령과 도구를 사용하도록 연결하는 Agentic Coding 환경이자 Agent Harness입니다. 모델의 행동 선택과 실행환경의 권한·도구·Context 관리가 결합됩니다.

Claude Agent SDK는 이 실행 능력을 다른 프로그램에서 제어하는 인터페이스입니다. 이 교재는 Claude Code를 직접 사용하고 확장하는 관점에서 출발해, 실행·기억·절차·협업·보안과 반도체 분석의 검증 조건을 연결합니다.

학습 원문을 근거로 재구성한 안내입니다. 원문의 근거 표기와 검증 범위를 함께 확인하세요.

서로 구분하며 읽을 개념

Claude 모델 / Claude Code / Agent SDK
추론과 도구 요청을 생성하는 모델, 이를 실제 환경과 연결하는 Harness, 앱에서 호출하는 프로그램 인터페이스를 구분합니다.
지시 / 기억 / 절차 / 실행 제어
CLAUDE.md·AGENTS.md는 지침, Auto Memory는 프로젝트 기억, Skill은 작업 지식입니다. Hook·Permission·Sandbox와 실제 자원 권한은 별도 통제 계층입니다.
실행 성공 / 분석 정확성 / 공개 확인 범위
명령이 성공해도 수치와 근거가 참인지는 별도 검증이 필요합니다. 공개 저장소의 존재가 CLI 엔진 전체 소스 공개를 의미하지도 않습니다.
