범위: 설계·구조·사용·운영·보안·확장·평가·적용 검토. 실제 데모 구현이나 성능 벤치마크는 이 문서에서 수행하지 않음.

읽기 전에 — 신뢰도 표시와 코드 분석의 한계#

이 문서는 다음 네 가지 근거 등급을 구분한다.

  • [공식 문서]: Anthropic이 문서에서 공개적으로 설명한 기능·동작. 버전·플랫폼·계정 조건에 따라 달라질 수 있다.
  • [공개 자료 확인]: 공식 CLI 레퍼런스, 설정 스키마, 예제, 공식 GitHub 저장소의 공개 파일·릴리스 노트에 직접 나타나는 사실.
  • [개념 모델/의사코드]: 여러 공식 설명을 학습에 유리하도록 재구성한 개략 구조. 내부 구현 소스코드가 아니다.
  • [설계 제안]: 향후 반도체 Agent 개발에 도움이 될 수 있는 권장안. 제품 자체의 보장 기능이나 검증된 성능을 뜻하지 않는다.

중요: Claude Code의 공식 GitHub 저장소가 공개되어 있다고 해서 Claude Code CLI 엔진 전체가 소스코드 형태로 공개된 것은 아니다. 저장소에서 직접 조사할 수 있는 것은 README, 설정/예제/확장, 플러그인, 릴리스 기록 등 공개된 범위다. 아래의 while 반복문이나 정책 의사코드는 사용자 이해를 위한 모델일 뿐 Anthropic의 비공개 엔진에서 추출한 함수가 아니다. 반면, claude CLI 명령, settings.json 구조, SKILL.md/Subagent/Hooks의 파일 규격은 공식 문서에 따라 확인할 수 있다. [R01][R02][R03][R28]

공식 문서는 지속적으로 수정된다. 본문에 있는 버전별/실험적 기능은 재사용 전에 링크에서 다시 확인한다. 코드 예시는 별도 언급이 없으면 학습용 예시이며 실행 테스트를 완료한 코드는 아니다.
