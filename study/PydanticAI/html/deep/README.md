# PydanticAI — 2차 심층 학습 교재

이 폴더의 index.html을 브라우저에서 열어 읽습니다. 상위 html/index.html의 '2차 심층 교재' 링크로도 들어올 수 있습니다. 원문은 프레임워크 폴더 바로 아래에 유지하며, 기존 1차 교재의 본문을 보존했습니다.

## 구성과 읽기

- 총 21페이지: 심층 학습 안내 + 20개 읽기 단원.
- 원문 번호 장 27개, 전체 1,675행을 연속 범위로 빠짐없이 배치합니다.
- 문단·조건·표·질문·발표 구성·출처·비번호 요약을 보존합니다. 긴 워크북은 소주제 경계에서 나눕니다.
- 단원별 읽는 관점, 본문 세부 목차, 절 링크, 이전/다음 단원, 기본 교재와 다른 심층 교재 이동을 제공합니다.
- 23개 fenced 블록(코드·텍스트·Mermaid 포함), 도식 7개를 보존합니다.
- Flow와 State 도식은 로컬 SVG로 표시합니다. Sequence는 호출 방향·실선/점선·반복·분기·Note를 표로 표시하고 Mermaid 원문을 함께 보존합니다.
- 본문 17px, 줄 간격 1.8, 읽기 폭 76ch입니다. 긴 표·코드·도식은 해당 영역에서 가로로 스크롤합니다.

## 파일과 재생성

원문: [원본 Markdown](../../PydanticAI_2%EC%B0%A8_%EC%8B%AC%EC%B8%B5_%ED%95%99%EC%8A%B5_%EB%B6%84%EC%84%9D.md)

- build.mjs / site.config.mjs: 원문 전체의 연속 범위 분할, 단원 구성, 정적 HTML·SVG 생성
- deep.css: 공통 교재 스타일을 보완하는 심층 교재 스타일
- validate.mjs / validation.json: 원문·생성 내용 보존과 로컬 링크 검사
- content-map.json: SHA-256, 원문 행 범위·페이지 대응, 코드·도식·출처 목록
- browser-qa.json / preview-mobile.png: 브라우저 검사 기록과 미리보기

이 디렉터리에서 실행:

```sh
node build.mjs
node validate.mjs
```

생성에는 Node.js, marked, @viz-js/viz가 필요합니다. 현재 구현은 로컬 패키지 또는 Codex 번들 런타임의 패키지를 사용합니다. validate.mjs도 같은 런타임의 marked로 원문을 독립적으로 다시 파싱합니다. 완성된 페이지 열기에는 Node.js나 서버가 필요하지 않습니다. 상위 html/의 style.css·site.js·아이콘을 사용하므로 html/ 디렉터리 전체를 함께 유지하세요. 외부 출처를 제외한 모든 학습 콘텐츠는 오프라인으로 읽을 수 있습니다.

기본 교재의 build.mjs와 심층 교재의 build.mjs는 상위 link-courses.mjs를 호출합니다. 기본 교재를 다시 생성해도 두 과정의 이동 링크가 유지됩니다.
