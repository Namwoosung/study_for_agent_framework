6. Runner.run → _run_impl: 상위 호출 분석#

src/agents/run.py에서는 Runner.run(...)/AgentRunner.run(...) 진입 시 RunConfig의 정규화, Tracing 설정, 도구 구성 보호 컨텍스트, 모델 Provider 자원의 소유권 등을 관리한 뒤 내부 _run_impl에 위임한다. [SRC: S01]

관찰된 핵심 구조:

  1. run(...)이 run_config와 Provider 소유권을 정리한다.
  2. 예외와 Tracing을 감싸는 실행 스코프를 만든다.
  3. 구성 기준 Agent를 정한다. 이어지는 RunState 재개면 저장된 현재 Agent가 사용될 수 있다.
  4. agent_tool_configuration_run(...) 안에서 _run_impl(...)을 호출한다.
  5. 생성한 Provider를 본 실행이 소유한 경우 finally에서 정리한다.
  6. _run_impl은 RunState 재개 여부, max_turns, hooks, session, 대화 ID와 Response ID 옵션을 받아 처리한다.

왜 관심 가져야 할까? 외부 Agent 요청이 단순히 모델 호출을 감싸는 것이 아니라, 자원 소유권, 예외와 민감정보, 저장 상태, 실행 정책을 함께 가진다는 점을 보여준다.

학습용 의사코드·구조 예시 · 본문에서 실제 코드 여부 확인python
# [PSEUDO] 공개 run.py의 계층을 학습용으로 축약한 구조
async def run(agent, input, config):
    provider, owns_provider = normalize_provider(config)
    try:
        with tracing_scope(config), guarded_agent_tool_configuration(agent):
            return await _run_impl(agent, input, config)
    finally:
        if owns_provider:
            await close_provider(provider)

이는 실제 SDK 함수 구현을 그대로 인용한 것이 아니며 공개 소스의 책임 분리를 보여주는 그림이다.

6.1 Resume가 새 Run과 달라지는 지점#

input이 RunState인지 확인하고 원래 입력, 직전 Current Agent, 승인 정보, 모델 대화 연결 설정 및 재개 상태를 복원한다. 단순히 원래 사용자 문장을 처음부터 다시 실행하는 방식이 아니어야 이중 실행을 줄일 수 있다. 단, 외부 Tool 부작용에 대한 exactly-once를 SDK 단독으로 보장하는 것은 아니다. [SRC: S01, S09]

6.2 상태에 따라 다른 모델 입력#

최초 요청은 새 입력과 Session 기록을 조합할 수 있다. Resume는 normalize_resumed_input(...), 승인 결정을 포함한 RunState와 현재까지 생성된 RunItem을 반영한다. Server conversation ID/previous response ID 방식은 로컬 Session 기록을 매번 전부 재전송하는 방식과 다르다. [SRC: S01, S08]

7. 단일 모델 Turn은 무엇을 수행하는가?#

한 번의 반복에서 실행되는 핵심 단계:

  1. 현재 Agent의 모델·지시문·도구 목록·Handoff·출력 스키마를 준비.
  2. 모델에 전달할 입력 메시지를 준비·필요한 경우 필터링.
  3. 모델 API 호출(정상 응답 또는 스트림).
  4. process_model_response(...)로 모델 출력 항목을 실행 가능한 SDK 내부 항목으로 변환.
  5. Tool 실행/승인, Handoff·Final 분기.
  6. RunItem·Session·Tracing·사용량·현재 Agent 상태 반영.
  7. NextStep에 따라 종료, 다음 모델 호출, 다른 Agent로 이동, 승인 대기.

모델이 스스로 Python 함수를 호출하는 것은 아니다. 모델은 구조화된 Function Call을 출력하고, 실제 Python 실행 여부는 런타임이 결정한다.
