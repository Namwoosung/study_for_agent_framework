# 학습자료

[전체 학습 홈](index.html)에서 7개 주제의 기본·심층 교재와 단원으로 이동합니다.

각 기술 폴더의 Markdown은 학습 원문이며, `html/`은 원문을 읽기 좋게 재구성한 교재입니다. `html/deep/`은 2차 심층 교재입니다. 발표·실무 시사점 코멘트는 관련 기술 폴더에 함께 있습니다.

[7종 종합 비교](Agent_Framework_7종_최종_종합_비교_분석.md)도 이 폴더에 모았습니다.

공통 홈·코멘트의 생성 및 검증 스크립트는 이 폴더의 `html/`에 있습니다. 프로젝트 루트에서 `node study/html/build-home.mjs`로 갱신합니다.
