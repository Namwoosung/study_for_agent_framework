53. 버전 고정 범위 — 중요한 주의사항#

Claude Code v2.1.314와 Claude Agent SDK Python v0.2.174는 서로 다른 프로젝트·버전 체계다. SDK의 공개 파일을 v0.2.174 기준으로 분석한다고 해서 해당 SDK가 언제나 최신 CLI v2.1.314의 모든 기능을 제어할 수 있다는 뜻은 아니다. 문서가 명시한 SDK API·CLI 버전 호환성과 설치 환경을 별도 확인해야 한다.

이 자료는 문서화된 기능과 공개 SDK 함수에 대한 정적 소스·문서 분석이다. 실제 Claude Code Binary를 역어셈블하거나, 실 실행 로그를 확보하거나, v2.1.314의 전체 내부 테스트를 수행한 보고서가 아니다. 그래서 다음은 사실로 적지 않는다.

  • 코어 Loop의 정확한 내부 함수·스택.
  • 비공개 Tool Scheduler의 Thread/Event Loop 구현.
  • 모든 Provider에서 동일한 캐시 동작·동일한 Permission 평가 순서.
  • Sandbox가 모든 Tool/OS/API 작업을 완전히 격리한다는 주장.
  • 단순 Session Resume로 외부 부작용이 정확히 한 번 실행된다는 주장.
