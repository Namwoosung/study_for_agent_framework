# Microsoft Agent Framework 학습 페이지

원본 `../Microsoft_Agent_Framework.md`를 보존하고 웹 관련 파일을 이 폴더에 모았습니다.
원문 기준은 2026-10-31, Python SDK `python-1.24.0` / 커밋 `43d767c`입니다.

## 열기

`index.html`을 브라우저에서 열면 됩니다. 인터넷 연결 없이 본문·표·코드·도식을 읽을 수 있습니다. 공식 외부 출처 링크는 인터넷 연결이 필요합니다.

학습 안내, 11개 단원, 핵심 복습, 출처와 검증 범위의 총 14페이지입니다. 원문의 38개 장과 앞부분 안내, 코드 블록 36개, Mermaid 도식 9개를 수록했습니다. 흐름도는 로컬 SVG, 시퀀스는 호출·분기 순서표로 표시하고 원본 Mermaid도 펼쳐 볼 수 있습니다.

## 파일

- `site.config.mjs`: 단원 배치와 원문에 근거한 학습 도입
- `build.mjs`: Markdown을 정적 HTML·SVG로 변환
- `validate.mjs`: 원문 해시, 코드 보존, 장 배치, 도식, 파일·앵커 링크 확인
- `style.css`, `site.js`: 반응형 교재 스타일과 좁은 화면 목차
- `content-map.json`: 원문 해시, 페이지·장 대응, 출처와 코드·도식 목록
- `assets/`: 로컬 도식과 아이콘
- `preview.png`: 브라우저 미리보기

## 재생성과 검사

이 폴더에서 실행합니다.

```sh
node build.mjs
node validate.mjs
```

생성 시 Node.js와 `marked`, `@viz-js/viz`가 필요합니다. 현재 환경에서는 Codex 번들 런타임의 패키지를 대체 경로로 사용합니다. 완성된 HTML 열기에는 Node.js나 패키지가 필요하지 않습니다.

## 확인 범위

14페이지, 원문 영역 39개(38장 + 도입), 코드 블록 36개, 도식 9개, 내부 링크 552개 검사 통과. 원문 SHA-256 일치, 코드 원문 보존과 각 장의 단일 배치를 확인했습니다. HTTP 200과 좁은 브라우저 화면의 제목·목차 개폐·도식·호출 순서표를 확인했습니다. 별도 데스크톱 해상도와 실물 모바일 기기 검사는 수행하지 않았습니다.

웹페이지 제작은 제공된 자료를 편집·표시하는 작업입니다. 최신 API·공식 링크의 현재 상태를 추가 조사하거나 SDK 설치·모델 호출·DB·MCP·승인 재개·Checkpoint 복구를 실행하지 않았습니다. 원문의 공식 문서·공개 코드·의사코드·설계 제안·미검증 구분을 유지합니다.
