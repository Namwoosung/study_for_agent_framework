Agent Pipeline·Tool Loop·Harness Loop·Workflow의 제어권을 나눕니다.

원문 2026.10.31 · Python SDK python-1.24.0 · 원문 30개 장 · 19개 읽기 단원

기능에서 실행 책임으로

하나의 거대한 Loop 대신 외부 Agent Pipeline, ChatClient의 Function Invocation, 선택적 Harness 반복과 명시적 Workflow를 구분합니다. 상태 commit·승인 바인딩·복구와 외부 부작용의 경계를 고정 소스에 연결합니다.

1차 교재에서 객체와 기능을 익혔다면, 이번에는 요청 진입 → 모델 입력 → 도구 실행 → 상태 저장 → 종료·실패·복구를 연결해 읽습니다. 긴 워크북은 원문 소주제 경계에서 나눴으며, 설명·조건·코드·표·질문·출처를 요약으로 대체하지 않았습니다.

원문이 구분하는 공개 코드·공식 문서·설계 해석·의사코드·미검증 범위를 함께 읽으세요. 1차와 2차의 버전은 다를 수 있습니다. 이번 웹페이지 제작은 제공된 문서의 편집·표시이며 최신 API의 추가 조사나 실제 실행 검증이 아닙니다.

구분하면서 읽을 세 가지

모델 입력 / 저장된 기록
저장소에 있는 정보와 현재 요청에서 모델이 볼 수 있는 정보는 다릅니다.
실행 취소 / 외부 효과 복구
Task나 스트림을 끝내도 이미 발생한 파일·DB·API 변경까지 되돌아가지는 않습니다.
공식 계약 / 공개 코드 / 설계 해석
문서에 명시된 동작, 고정 소스에서 확인한 경로, 재구성한 의사코드와 미검증 항목을 구분합니다.
