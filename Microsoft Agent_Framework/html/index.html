먼저 잡을 큰 그림

Microsoft Agent Framework는 모델이 도구를 선택하는 Agent와 개발자가 실행 경로를 정의하는 Workflow를 함께 구성하는 개발 프레임워크입니다. Harness는 계획·파일 메모리·승인 같은 기능을 조합하고, Integrations는 외부 모델과 도구·저장소를 연결합니다.

예를 들어 수율을 계산하고 검증하는 단계는 일반 코드와 Workflow로 명시하고, 그 결과에서 원인 가설을 정리하는 단계에 Agent를 배치할 수 있습니다. 어떤 계층이 반복·저장·인가를 맡는지 구분하면 기능 목록을 실제 설계 기준으로 연결할 수 있습니다.

학습 원문을 근거로 재구성한 안내입니다. 원문의 근거 표기와 검증 범위를 함께 확인하세요.

서로 구분하며 읽을 개념

Agent / Workflow / Harness
Agent는 모델 기반 판단을, Workflow는 Executor와 Edge의 실행 경로를, Harness는 여러 운영 기능의 합성을 다룹니다.
Tool Loop / Agent 전체 재실행
FunctionInvocation의 모델·도구 반복과 AgentLoopMiddleware의 Agent 전체 반복은 적용 위치와 종료 조건이 다릅니다.
Session / Context / Checkpoint
대화 연속성, 모델 입력 준비, Workflow 실행 위치 복원은 저장 대상과 수명이 다릅니다. 외부 작업의 중복 방지는 별도로 설계합니다.

이 교재의 범위

상위 폴더의 Microsoft_Agent_Framework.md를 바탕으로 편집했습니다. 본문·코드·표·출처와 원문의 제약을 보존하며, 도식은 로컬에서 읽을 수 있도록 다시 표시합니다.
