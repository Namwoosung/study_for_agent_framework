먼저 잡을 큰 그림

Claude Agent SDK는 모델 API를 직접 호출하는 클라이언트와 다릅니다. Claude Code의 Agent 실행 기능을 Python 또는 TypeScript 애플리케이션에서 프로그래밍 방식으로 제어하는 인터페이스입니다.

공개 Python SDK에서 입력·설정 직렬화, 프로세스 통신, 메시지 파싱과 제어 프로토콜을 읽을 수 있습니다. 하지만 이것이 별도 CLI 내부의 모든 모델·도구 반복 알고리즘을 확인했다는 뜻은 아닙니다. 이 경계를 기준으로 통제와 확장 범위를 배웁니다.

학습 원문을 근거로 재구성한 안내입니다. 원문의 근거 표기와 검증 범위를 함께 확인하세요.

서로 구분하며 읽을 개념

Python SDK / Claude Code CLI / 모델 API
SDK는 통신과 제어를 연결하고, CLI 실행 환경은 도구·Context·반복을 관리하며, 모델은 응답과 도구 요청을 생성합니다.
도구 노출 / 자동 승인 / 실제 권한
tools, allowed_tools, disallowed_tools는 같은 설정이 아닙니다. 특히 allowed_tools는 단독 차단 목록이 아닌 자동 승인 규칙입니다.
Session / Auto Memory / Skills / RAG
작업 이력, 프로젝트 기억, 재사용 절차와 외부 지식 검색은 서로 다른 저장·선택·검증 정책이 필요합니다.
