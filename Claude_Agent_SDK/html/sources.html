문서를 읽는 방법과 검증 기준#

  • [공식]: Anthropic의 공식 문서 또는 공식 릴리스에 명시된 사실.
  • [소스]: 고정된 Python SDK 태그에서 확인한 함수·클래스·분기 로직.
  • [추론]: 공식 설명과 공개 구조를 근거로 한 해석. 확정된 내부 구현이라고 주장하지 않음.
  • [설계]: 향후 반도체 데모에 권장하는 접근. SDK의 내장 기능과 혼동하지 않음.
  • [의사코드]: 전체 구조를 배우기 위해 간략화한 코드. 실제 SDK 소스나 실행 가능한 예제와 구분.
  • 출처는 본문에 [[D01]](https://code.claude.com/docs/en/agent-sdk/overview), [[C01]](https://github.com/anthropics/claude-agent-sdk-python/blob/v0.2.174/src/claude_agent_sdk/query.py) 형식으로 표시하고 마지막 장에 클릭 가능한 원문 URL과 역할을 제공한다. 공식 웹 문서는 계속 업데이트될 수 있으므로 2026-10-29 시점의 최신 문서와 고정 태그 간 차이는 별도로 주의한다.
  • 중요: Claude Agent SDK의 공개 Python 코드와 별도로 실행되는 Claude Code CLI 내부 Agent Loop는 공개 범위가 다르다. SDK 공개 코드만으로 CLI의 모든 내부 알고리즘을 검증했다고 말할 수 없다.

30.1 출처 검증 정책#

이 문서의 기술적 사실은 아래 Anthropic 공식 문서와 GitHub 저장소를 우선했다. 웹 문서는 업데이트될 수 있으므로 코드 주장에는 v0.2.174 태그 링크를 사용했다. 코드 발췌보다는 함수명·파일·역할·처리 흐름과 원문 링크를 제공했다. 소스가 공개되지 않은 CLI 내부 메커니즘은 공식 동작 설명 범위 안에서만 기술했다.

30.2 버전별 주의사항 (문서화된 변경·관찰 지점)#

  • v0.2.174 (2026-10-24): 공식 릴리스 페이지에서 번들 Claude CLI가 2.1.310으로 변경되었다고 명시. [C00]
  • v0.2.170 (2026-10-21): 병렬 Tool 호출이 있을 때 세션 메시지 조회에서 일부 Tool 호출/결과가 누락되던 문제 수정이 릴리스 노트에 기재. 오래된 버전의 감사 추적 신뢰도를 비교할 때 중요하다. 공식 릴리스 목록
  • Skills 기본값: v0.2.174의 _apply_skills_defaults()는 skills가 지정된 경우 Tool 승인과 setting sources의 기본값을 계산한다. [C05] 최신 문서에서의 setting_sources 생략 동작과 함께 확인해야 한다. [D12]
  • Managed Policy/Auto Memory: setting_sources=[]만으로 CLI가 참조하는 모든 설정과 자동 메모리가 없어지는 것은 아니라는 주의가 최신 문서에 있다. 다중 사용자 환경에서는 CLI 설정 디렉터리와 자동 메모리 정책까지 통제해야 한다. [D12]
  • Hooks/Permissions: 최신 공식 문서가 기술하는 일부 예외 동작은 SDK 자체보다는 함께 번들된 CLI 버전에 의해 달라질 수 있다. [D06], [D07]

30.3 정보의 공개·비공개 경계#

  1. 확실히 코드로 볼 수 있는 것: Python query, Client, Control Protocol, CLI 프로세스 실행, 메시지 파서, SDK MCP Bridge, SessionStore 연동.
  2. 공식 문서로 동작이 설명되는 것: Claude Code Agent Loop, Built-in Tool 실행, Context Compaction, Subagent 위임, 권한 정책.
  3. 직접 소스 증거가 부족한 것: 번들 CLI 내부 모델 호출 상태 머신의 모든 함수, 모든 휴리스틱, 모델의 Tool 선택 결정 근거.
  4. 향후 실행으로 검증할 것: 보안 정책의 실제 차단율, 기능별 성능, 도구 재시도·복구, Session 품질, 사내 환경 호환성.
