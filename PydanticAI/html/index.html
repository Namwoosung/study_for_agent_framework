먼저 잡을 큰 그림

PydanticAI는 Python 타입과 Pydantic 스키마를 활용해 모델·도구·의존성·출력을 구성하는 Agent 개발 프레임워크입니다. 모델 자체나 모델을 GPU에 올리는 추론 서버가 아닙니다.

Agent는 정의와 설정을, 내부 pydantic-graph 노드는 실행 흐름을 담당합니다. 이 교재에서는 모델의 요청이 도구 검증·실행과 출력 검증·재시도를 거쳐 결과가 되는 과정을 연결합니다. 스키마에 맞는 값과 실제로 참인 값은 구분해야 합니다.

학습 원문을 근거로 재구성한 안내입니다. 원문의 근거 표기와 검증 범위를 함께 확인하세요.

필드·타입·범위가 맞아도 업무 규칙이나 원본 데이터와 다를 수 있습니다. 수치 재계산과 출처 대조는 별도 검증입니다.

이 교재의 범위

상위 폴더의 PydanticAI.md를 바탕으로 편집했습니다. 본문·코드·표·출처와 원문의 제약을 보존하며, 도식은 로컬에서 읽을 수 있도록 다시 표시합니다.

PydanticAI v2.61.0 중심의 원문 조사본이며, Core와 별도 Harness·Graph·Evals·관측 도구의 범위를 구분합니다. 이번 웹페이지 제작은 원문의 편집·표시 작업입니다. 최신 API나 구현을 추가 조사한 것으로 간주하지 않으며, 실제 설치·모델 호출·벤치마크는 수행하지 않았습니다.
