0.3 1분 핵심 요약#

PydanticAI는 Python으로 LLM Agent를 정의·실행하기 위한 타입 중심(type-safe) Agent 프레임워크다. 개발자는 모델, 지시문, 도구, 의존성, 기대 출력 타입을 선언한다. 프레임워크는 모델 호출 → 도구 실행/출력 해석 → 검증·재시도 → 최종 결과 반환을 관리한다. 내부 구현은 pydantic-graph 기반 실행 노드를 사용한다. [S03][C02]

반드시 기억할 7가지:

  1. Pydantic = 데이터 검증 라이브러리, PydanticAI = LLM Agent를 만드는 프레임워크. 같은 제품이 아니다.
  2. Agent는 모델 자체가 아니다. 모델 호출과 반복·도구·출력을 조율하는 개발용 추상화다.
  3. deps_type과 RunContext를 통해 DB 클라이언트·사용자 권한 등 런타임 의존성을 주입한다. 이를 LLM에게 모두 전달하는 것은 아니다.
  4. output_type은 타입/구조 검증에 유리하지만, 모델이 생성한 수치·원인·근거의 사실적 정답을 자동 보증하지 않는다.
  5. ToolManager는 도구 스키마 검증과 실행을 분리한다. 모델이 Tool을 '요청'하고, 실제 Tool은 호스트 코드가 실행한다. [C03]
  6. 대화 기록 유지와 장기 기억 검색은 구별해야 한다. 장기 Memory·Skills·Compaction 등은 별도 Harness/Capabilities로 확장 가능하다. [S04][S05]
  7. 실제 개발에서는 프레임워크 기능뿐 아니라 모델 접근 방식, 사내 데이터 통제, 검증 정책, 실행 격리, 평가 설계가 품질을 좌우한다.

버전 고정 및 재검증 메모#

  • 해당 시점의 공식 릴리스에서 확인한 최신 태그는 v2.61.0이다.
  • 실제 개발 전에는 python 요구 버전과 pydantic-ai-harness의 독립 버전 정책을 다시 확인해야 한다.
  • 내부 _... 파일과 메서드는 비공개 구현 상세(private API)이며 이후 버전에서 변경될 수 있으므로, 애플리케이션에서는 가급적 공개 API를 사용한다.
  • 모델의 정답률·Tool 호출 성공률·응답 시간·비용 등 성능 비교 수치는 아직 측정하지 않았다. 향후 동일 환경 실험에서 계측해야 한다.
