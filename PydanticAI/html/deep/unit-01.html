PydanticAI — 2차 심층 학습 및 내부 소스코드 분석#

학습 목적: PydanticAI를 어떻게 쓰는지보다, 내부에서 Agent Loop를 어떻게 구현하고, 호출·검증·상태·병렬·승인·메모리를 왜 그런 방식으로 제어하는지 이해한다. 향후 자체 Agent Framework/Harness의 구조를 설계하거나 다른 프레임워크와 비교할 수 있는 수준을 목표로 한다.

범위: 2026-10-31 기준으로 확인 가능한 PydanticAI Python Core v2.61.0 (Git tag v2.61.0, 발표일 2026-10-23). pydantic-ai-harness는 별도 패키지로, 해당 시점의 공식 문서에서 확인 가능한 기능을 소개하되 Core와 같은 버전이라고 가정하지 않는다.

제외: 반도체 Agent 데모 제작 및 실행, 실제 서버 배포, 성능 벤치마크. 코드 예시는 학습용이며 실행 검증을 했다고 주장하지 않는다.

근거 기호: [SRC] 고정 버전 공개 소스 직접 확인 · [DOC] 공식 기술 문서 · [INF] 소스/문서 기반 설계적 해석 · [UNV] 별도 실행·검증 필요.
