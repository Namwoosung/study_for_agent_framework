파일: capabilities/, agent/__init__.py

  • Run 시작/종료 Hook은 어디서 호출하는가?
  • Model Request 직전 Tool을 필터링하는 Capability는 어떤 데이터에 접근하는가?
  • Tool Call 직전·후처리 Hook에 전달되는 인자는 무엇인가?
  • Streaming Hook은 단순한 후처리와 어떻게 다른가?
